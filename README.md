# 🚀 Learning System

A modern learning platform designed to bring multiple programming learning resources into a single application. The goal of this project is to provide learners with a unified platform for coding practice, interview preparation, learning resources, and progress tracking.

---

## 📌 Project Overview

Learning System is a web-based platform that integrates various learning features into one dashboard. Instead of switching between multiple websites, users can access learning content, coding practice, interview preparation, and progress analytics from one place.

---

## ✨ Features

- 📊 Interactive Learning Dashboard
- 📈 Weekly Learning Analytics
- 🔥 Coding Activity Heatmap
- 💻 Programming Language Statistics
- 🎯 Continue Learning Section
- 📚 Recommended Learning Resources
- 🎨 Modern Responsive UI
- 🌙 Dark Theme Dashboard

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/pajjuri-saiteja/Learning-System.git
```

### Install Dependencies

```bash
cd frontend
npm install
```

### Run the Application

```bash
npm run dev
```
